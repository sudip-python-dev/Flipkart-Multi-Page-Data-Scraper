# Flipkart Multi-Page Scraper (Pagination)

### 📌 Project Overview
This advanced Python web scraper is designed to extract product data across **multiple pages** on Flipkart. Unlike basic single-page scrapers, it automatically navigates through pagination to collect large datasets from entire product categories.

### ✨ Key Features
* **Automated Pagination**: Automatically detects and processes multiple pages to scrape all available products in a category.
* **Bulk Data Extraction**: Scrapes hundreds of product details including Names, Prices, Ratings, Reviews, and Image URLs in a single script run.
* **Data Structuring**: Uses Pandas to organize the massive amount of raw data into a clean, structured format.

### 🛠️ Technologies Used
* **Python**: Core language.
* **BeautifulSoup**: For parsing complex HTML structures.
* **Requests**: For handling multiple HTTP requests efficiently.
* **Pandas**: For data cleaning and exporting to CSV/Excel formats.

### 📂 Output Format
The script generates a comprehensive, ready-to-use **CSV** or **Excel** file containing data from all the scraped pages, perfect for bulk analysis.
